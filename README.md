# Zenith-Habit-Tracker

Zenith is a modern iOS habit tracking and productivity app built with SwiftUI. The app helps users organize their daily routines, build consistency through streaks, manage reminders, and visualize progress with clean and intuitive statistics.

## Features

* ✨ Modern SwiftUI interface
* 📊 Habit tracking with completion progress
* 🔥 Daily streak system
* ⏰ Smart reminders and alarms
* 📅 Daily scheduling with draggable time slots
* 📈 Weekly and monthly statistics
* 🎨 Custom themes and design system
* 👤 Personalized onboarding experience
* 🔔 Local notification support
* 🧩 Modular and scalable architecture

## Screens

* Onboarding Flow
* Home Dashboard
* Today Planner

* Alarm Management
* Settings

## Tech Stack

* **Language:** Swift
* **Framework:** SwiftUI
* **Architecture:** ObservableObject State Management
* **Notifications:** UserNotifications Framework
* **Platform:** iOS
* **IDE:** Xcode

## Getting Started

### Requirements

* macOS
* Xcode 15+
* iOS 17+
* Swift 5.9+

### Installation

1. Clone the repository:

```bash
git clone https://github.com/pavlomaratheas/Zenith-Habit-Tracker.git
```

2. Open the project:

```bash
cd zenith
open Zenith.xcodeproj
```

3. Run the app on a simulator or physical device.

## App Overview

Zenith is designed to make personal growth and productivity easier to manage. Users can:

* Create and organize habits
* Track daily progress
* Schedule tasks during the day
* Receive reminders for habits
* Monitor consistency through streaks
* Analyze performance with visual statistics

The project focuses on simplicity, smooth animations, and a pleasant user experience.
